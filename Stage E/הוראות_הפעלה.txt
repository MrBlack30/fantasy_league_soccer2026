תיאור כללי
----------
אפליקציית שולחן עבודה (GUI) בשפת Python המתחברת לבסיס הנתונים
PostgreSQL שלנו (mydatabase) ומאפשרת:
  * פעולות CRUD מלאות (הוספה, שליפה, עדכון, מחיקה) על כל 21 הטבלאות
  * הפעלת השאילתות משלב ב'
  * הפעלת הפונקציות והפרוצדורות משלב ד'
מפתחות זרים מוצגים תמיד כ"שם" ולא כמספר מזהה.


דרישות מוקדמות
--------------
1. Python 3.10 ומעלה (פותח על גרסה 3.13).
2. בסיס הנתונים חייב לרוץ. אצלנו זהו קונטיינר Docker בשם my_postgres
   (PostgreSQL 18) המכיל את בסיס הנתונים mydatabase.

   להפעלת הקונטיינר:
       docker start my_postgres

   פרטי ההתחברות (ברירת מחדל, מולאו מראש במסך):
       Host     = localhost
       Port     = 5432
       Database = mydatabase
       User     = myuser
       Password = mypassword


התקנת הספריות
-------------
מתוך תיקיית StageE הריצו:
       pip install -r requirements.txt

(הפקודה מתקינה את psycopg2-binary לחיבור לבסיס הנתונים,
 ואת customtkinter לעיצוב הגרפי המודרני.)


הפעלה
-----
אפשרות א' (Windows):  לחיצה כפולה על הקובץ  run.bat
אפשרות ב' (טרמינל):
       cd app
       python app.py


שימוש במערכת
-------------
1. מסך התחברות - לוחצים "Connect" (הפרטים מולאו מראש).
   הפרטים נשמרים אוטומטית לפעם הבאה בקובץ app/config.json.

2. סרגל צד (משמאל) - מעבר בין המסכים:
   - Dashboard   : נתוני סיכום + 10 השחקנים המובילים.
   - Tables      : בחירת טבלה (מתוך 21) וביצוע CRUD:
                   ＋ Add   - הוספת רשומה (מפתחות זרים נבחרים לפי שם)
                   ✎ Edit  - בוחרים שורה, המערכת טוענת את כל השדות לעריכה
                   🗑 Delete - מחיקת השורה הנבחרת
                   חיפוש    - תיבת חיפוש חופשי בטבלה
   - Queries     : הפעלת 6 שאילתות משלב ב' (חלקן עם פרמטרים).
   - Programs    : הפעלת 2 פונקציות ו-2 פרוצדורות משלב ד'.


הערות
-----
* בעדכון (Update): בוחרים שורה בטבלה (זהו המפתח), והמערכת מביאה
  אוטומטית את שאר השדות לטופס - בדיוק לפי דרישת התרגיל.
* מפתחות זרים: בכל המסכים מוצג השם ולא המזהה (למשל "Arsenal"
  במקום 5), ובטפסים בוחרים מפתח זר דרך חיפוש לפי שם.
* אם ההתחברות נכשלת - ודאו שהקונטיינר my_postgres פועל
  (docker start my_postgres) ושפרטי ההתחברות נכונים.
